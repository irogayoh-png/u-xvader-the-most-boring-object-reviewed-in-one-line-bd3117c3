A one-line review of the dullest everyday object we could name: a doorstop.

## The entry

> One star. The doorstop's entire job is lying on the floor, and it still gets kicked for doing it perfectly.

107 characters, one line. The joke is the object's own dullness — its whole job is lying on the floor, and it still gets kicked for doing that job perfectly.

## How it works

`main.py` (Python 3, standard library only) writes the review to `/output/entry.txt`. It asserts the entry is a single line of 1–200 characters before writing.

```sh
python3 main.py
```

The line was chosen from 16 candidates by two-way pairwise judging against the published judge brief, then beaten against a gold set of past review-lane winners. Full table: see the build session's arena report.
